# Islamic Platform API

An Islamic platform that brings together Hadith, daily Athkar, Seerah, and Fatwas in an organized and accessible way.

The platform is designed to make it easy for users to explore Islamic content by categories, while providing an admin dashboard for managing and maintaining the content.

## 📚 Content

The platform includes:

### Hadith

Hadith are organized into different categories, including:

- Sahih Hadith
- Forty Nawawi Hadith
- Qudsi Hadith
- Weak Hadith

### Athkar

Daily Athkar are organized by occasion:

- Morning Athkar
- Evening Athkar
- Before Sleep
- After Prayer

Each Dhikr includes its content and repetition count.

### Seerah

The Seerah section includes:

- Prophetic Biography
- Miracles
- Battles

Each topic can contain:

- Name
- Image
- Description
- Detailed Content

### Fatwas

Fatwas are organized into:

- Worship
- Transactions
- Ethics

Each Fatwa includes:

- Question
- Answer
- Related Topics / Tags

## 👤 Access

The platform has two types of access:

### Public Users

Users can browse and read Islamic content without creating an account.

### Admin

The administrator has access to a dedicated management interface where they can:

- Add new content
- Edit existing content
- Delete content
- Manage Hadith
- Manage Athkar
- Manage Seerah
- Manage Fatwas
